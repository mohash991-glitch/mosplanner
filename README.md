# Mo's Planner

A personal day planner that installs on a phone's home screen: timed tasks with deliverables, importance levels, thumbnails, a daily quote, and light/dark modes.

Everything you enter (tasks, images, banner) is stored only on your device. Nothing is sent to this repository or any server.

**Install:** open the site in Safari (iPhone: Share → Add to Home Screen) or Chrome (Android: ⋮ → Install app).
